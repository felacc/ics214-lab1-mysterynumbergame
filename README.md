# Mystery Number Game

In this lab assignment I made a mystery number game where the user guesses a
randomly generated number within a range that they provide.

## Lab Learning Objectives
1. Write a basic .cpp file with a main function.
2. Use std::cout and std:cin for basic input and output.
3. Declare and use primitive variable types: int, double, char.
4. Use function return values.
5. Pass parameters by value.
6. Use the srand() and rand() functions to get a random value.
7. Handle invalid text input.
